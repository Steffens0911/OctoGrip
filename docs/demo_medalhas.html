Lógica de Medalhas — Correção

trophy_service.py · _tier_from_counts()

❌ Lógica Antiga (errada)

Cada tier contava apenas sua própria faixa

🥉Bronze: só brancos ≥ target
🥈Prata: só azuis ≥ target
🥇Ouro: só roxas+ ≥ target

Problema: aluno com 3 brancos + 2 azuis não ganhava bronze (meta 5), pois brancos e azuis eram contados separados.

✅ Lógica Nova (correta)

Tiers acumulativos — superior inclui inferior

🥉Bronze: qualquer faixa (branco+azul+roxa+) ≥ target
🥈Prata: azul ou superior (azul+roxa+) ≥ target
🥇Ouro: roxa ou superior ≥ target

Correto: posição contra faixa superior conta para todos os tiers inferiores também.
