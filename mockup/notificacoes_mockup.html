Plano de implementação
Backend (FastAPI)
  • Tabela notifications (id, user_id, type, title, body, read, created_at)
  • GET /notifications — lista paginada do usuário
  • GET /notifications/unread-count — só o número
  • POST /notifications/{id}/read — marcar lida
  • POST /notifications/read-all — marcar todas lidas
  • Função utilitária create_notification() chamada ao confirmar missão, desbloquear troféu, etc.
Flutter (Viewer)
  • NotificationModel — modelo de dados
  • NotificationService — fetch, mark read, polling
  • Ícone carta na AppBar do MainShell com Badge (igual ao das missões)
  • NotificationsScreen — lista com filtros
  • Poll automático a cada 30s (ou via push já existente)
